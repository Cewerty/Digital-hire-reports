## Этап 14. Расширение типов и демоданных для админ-панели куратора

### T30. Добавить типы куратора и расширить типы кандидатов для админ-панели"

Файл: src/types/candidateReport.ts

Требования:

1. Добавь тип этапа воронки кандидата:
   export type PipelineStage = "uninterviewed" | "in_review" | "approved" | "rejected";

2. Расширь интерфейс Candidate:
   - Добавь обязательное поле: pipelineStage: PipelineStage;

3. Добавь типы для главной панели наставника/куратора:
   export interface CuratorEvent {
     id: string;
     timestamp: string; // например: "14:20" или "Вчера"
     text: string;
     candidateId?: string;
   }

   export interface CuratorProfile {
     id: string;
     fullName: string;
     avatarUrl?: string;
     direction: string;
     monthlySelectedCount: number;
     recentEvents: CuratorEvent[];
   }

Правила:
