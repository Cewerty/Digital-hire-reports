## Этап 13. Деплой на Vercel

### T27. Подготовить конфигурацию Vercel

**Описание:**  
Подготовить проект к размещению на Vercel как статического SPA.  
Настроить fallback на `index.html` для прямого открытия и перезагрузки клиентских маршрутов.

**Затрагиваемые файлы:**  
`vercel.json`, `README.md`

**Зависимости:**  
T26.

**Требования:**

- Использовать Vite framework preset.
- Build Command: `npm run build`.
- Output Directory: `dist`.
- Root Directory — директория с `package.json` frontend-приложения.
- Не добавлять серверные функции, backend или переменные окружения без необходимости.
- Добавить в `vercel.json` SPA fallback:

      {
        "rewrites": [
          {
            "source": "/(.*)",
            "destination": "/index.html"
          }
        ]
      }

**Критерии готовности:**  

- Конфигурация находится в корне frontend-приложения.
- `npm run verify` и `npm run build` завершаются успешно.
- README описывает настройки сборки и назначение SPA fallback.
- Секреты и локальные конфигурации с ключами не попадают в Git.
