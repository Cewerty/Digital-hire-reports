# Практический цикл на одну задачу

1. Берёшь T08 из плана: «Источники разделов».
2. Даёшь реализатору SPEC.md + список файлов + критерии.
3. Агент меняет код.
4. Запускаешь build/lint.
5. Сам кликаешь по интерфейсу.
6. Смотришь git diff.
7. Архитектор делает ревью diff.
8. При необходимости — отдельный фикс.
9. Делаешь коммит.
10. Берёшь следующую задачу.
